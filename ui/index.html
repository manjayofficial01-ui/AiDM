YouTube — signed-in access

yt-dlp runs as a separate process and cannot see your browser's login, so videos you can watch while signed in (private, members-only, age-confirmed) used to fail as “Sign in to confirm you’re not a bot”. Let yt-dlp read that browser's cookie store to fix it. Off by default — nothing is read until you choose a browser.

Cookies the browser extension captures are always forwarded, whatever you pick here.

AI Assistant — TokenHarbor

Features

When a copied URL matches no known pattern, Jev (TypeSafe System One) classifies it — confident downloadable links are captured, pages ignored. Fail-open: off or unreachable means old behavior. Key via TYPESAFE_API_KEY env only.

File hosts — Rapidgator

Free hoster accounts are forced through a wait timer and a captcha, which AiDM does not bypass. Add a premium account (or paste a logged-in session cookie) and Rapidgator links download immediately.

Leave both empty to use the free flow (wait required).
